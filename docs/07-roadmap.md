# 07 · Что дальше

## Presence по IMU (уже есть)

Детектор считает jerk и держит EMA. Порог `0.06 g` ловит касание/топот рядом. Это дешёвый и надёжный способ понять «человек рядом», если стик лежит на столе.

Идеи автоматизаций:

- `hyprlock` при `motion = false` дольше N минут;
- пауза музыки, когда вы отошли;
- уведомление в Telegram при движении в отсутствие хозяина;
- счётчик «сколько раз трогали стик за день».

## Presence по Wi-Fi RSSI (медленно, но бесконтактно)

Идея: следить за RSSI известной точки доступа. Человек, проходящий между стиком и роутером, меняет уровень сигнала на несколько дБ.

Проблемы:

- `scan()` занимает 2–4 с — разрешение по времени плохое;
- RSSI шумит на ±2–5 дБ в помещении;
- для быстрого RSSI нужен режим station (подключение к сети), а не scan.

План эксперимента:

1. 60 с покоя, зафиксировать mean/σ/min/max.
2. 60 с ходьбы между стиком и роутером.
3. Сравнить распределения; если разница средних ≥ 4 дБ — строить детектор с гистерезисом.
4. Иначе — оставить IMU.

## CSI: настоящий «радар»

ESP32 умеет отдавать **Channel State Information** — амплитуду/фазу по поднесущим. По изменениям CSI Detect движения и даже дыхания. Но:

- в MicroPython доступа к CSI нет;
- нужна C-прошивка (ESP-IDF `esp-csi` или Arduino);
- потребуется второй ESP32 в роли приёмника/передатчика (покупка или второй стик).

Без второго устройства можно сделать «эхо»-схему, но это уже исследовательский проект.

## Webhooks (уже есть)

Панель умеет отдавать события наружу. Задайте `ESP32_WEBHOOK`, и `motion`/`button` будут уходить POST-ом:

```bash
ESP32_WEBHOOK=http://127.0.0.1:9000/hook ./scripts/install-service.sh
```

```json
{"event": "motion", "kind": "motion", "text": "motion detected (0.12 g/s)", "score": 0.12}
```

Готовые потребители: `scripts/presence_lock.py` (hyprlock), `scripts/macro_pad.py` (кнопки), Home Assistant через webhook-триггер. MQTT пока нет — при желании добавляется в `_notify()` панели.

## Что не нужно покупать

Проект специально сделан без дополнительных модулей: всё, что нужно, уже есть на плате (IMU, Wi-Fi, бипер, LED, кнопки). Единственное ограничение — один UART и отсутствие CSI в MicroPython.
